神在吗 程苓峰 *Aug 21, 2026, 4:08 PM*

前天一个投资人在小群里提了一个问，有创业者接了话，然后一轮问答就在群里走开了。过程蛮有意思，把要点梳理在下面。人比较多，穿插在一起，就单纯的用 q 代表提问，用智叟代表回答。

q：腾讯猛做 workbuddy，也起量了，是不是胜负手？

智叟：不是。workbuddy 是容易上手，做产品也是腾讯强项，但也砸了很多钱。这东西放在软件时代算牛逼，但一个工具有人用，不等于在 ai 时代有粘性，不等于不会被大模型覆盖。

q：互联网遗留下来的 2c 平台，在 ai 面前的压力到底是什么？

智叟：老 2c 平台都无法自由的容纳 agent。所以你会看到它们只能限制 agent。

q：比如？

智叟：若允许 agent 发布短视频，抖音就崩了，海量内容到哪里找人来看。若让 agent 来看，抖音就不存在了，没人了。

q：美团淘宝呢？

智叟：若只允许自家 agent 进入，就无法让用户信任。gpt 和千问无法把购物做起来，就卡在这里，采购不能不接受监督。

若放开让agent 进入，那就白干了。它们提供数据，却是别人赚钱。所以必须限制。

q：意思是这些平台的价值可能归零？

智叟：每一家都在用 ai 做好之前的自己。但相反，它们必须生死相搏，去创造新的秩序结构，这是 ai 时代轻资产的皇冠。

q：轻资产的意思是？

智叟：大模型要不断投资改进，就算最强模型也会面临廉价模型的竞争。agent 也要演化，就像人类不断学习。算力会像发电厂一样卷效率和成本竞争。但承载线上社会的新秩序一旦形成就相对稳定，就像城市。

q：社会秩序其实是网络效应？

智叟：过去的网络只有人，新秩序是人 + agent，一旦越过临界点，不可能被替代。在一切都面临 ai 通缩的时代，新秩序的价值很可能是唯一扛通缩的。所谓秩序就是所有人的容器，是最强网络效应。

q：微信呢？

智叟：微信作为连接人和人的平台价值会贬值。你微信加上几十个不相干的人，就可以体验这个微信号的贬值。

q：但我为毛要加陌生人？我可以删。微信是双向机制，天然没垃圾信息。我甚至可以选不看谁，或不让谁看我。还不能防止 agent 泛滥？

智叟：双向机制足够保证连接人跟人的价值。但也自然限制了 agent 在微信里的活动。

q：少就是多，比如公众号每天只能发一条信息，适度限制恰恰能保障良性繁荣？

智叟：但风险是若能容纳更多的agent 跟人共生，可能成就一个新平台。

q：不要考虑数量，考虑机制本身。allenzhang 的方法论是，构建极简规则，让世界自己演化。这个持续有效？

智叟：确实微信跟其它 2c 平台有本质不同。其它是服务型平台，当 agent 提供类似服务，跟平台就直接冲突。微信是连接器，连接人跟服务，有一定扩容能力。

q：微信为什么不是在结构上天然容纳 agent？

智叟：微信允许 agent 进入的边界是，agent 不能代替人发信息，也不能代替人先看信息。就像元首通话，必须元首亲自听，亲自说。agent 只能是秘书。

q：不能让 agent 卡在人跟人中间？

智叟：那样 agent 会把人完全绑架。人成为不上朝的皇帝，太监一手遮天，那太监其实就成了皇。不是说 agent，而是 agent 背后的人成了皇帝。机器人总动员里，agent 最后敢于违抗船长的命令。

q： 那作为秘书是干嘛？

智叟：秘书的天条是只能处理直接连接之外的其它事，比如提建议。

q：人可以直接读公众号视频号，又为啥不能直接跟 agent 接触？

智叟：人可以跟 agent 直接连接。我们可以同时有部长和秘书的微信。但当我们微信部长本人时，不希望是秘书代读。若有事更适合联系秘书，当然可以直接问秘书。

q：agent 身份必须跟主人绑定，还是有独立身份？

智叟：形式上的绑定或不绑定都无所谓。但底层肯定绑定，奴隶背后必定有一个主人，要不杀了人谁负责。

q：agent 若不能代替主人跟其他人直连，会失去怎样的势能？

智叟：对微信本身没啥影响，但对商业价值影响巨大。若没视频号，微信作为熟人连接器不可动摇，但少赚钱。

q：若agent 可以代替主人直接跟其他人连，会不会必然产生一个新秩序？

智叟：新秩序也是一个连接器，其中包括人和 agent 的直接连接。它的生态位跟微信一样都是提供在线社会的基座。只是它需要不同结构，所以无法在微信现有的聊天结构中自然进化而出。

q：为什么它必然需要不同结构？

智叟：一个独立于人的智力第一次出现。所以在它出现以前的世界，不可能有容纳它的结构。新的智力要求新的结构。

q：观察微信的历史有个天条，一切新东西都是从人跟人的连接长出来，那能不能推出，agent 不能代替主人直接跟人连？

智叟：微信可以做什么在结构上受到两个约束：

1、agent 若破坏人跟人的直连，微信作为核心连接器的价值会下降。

2、新秩序必须重新发明，因为现有结构是为服务人这个单一智力设计的，新秩序需要同时服务两种智力主体。

q：那就必须回答，人跟 agent 两种智力的本质区别是什么？

智叟：人有天性，比如看到好内容会点赞转发，微信就靠这种天性。agent 可以模拟天性，但不是真有。所以它们会发垃圾，抓数据，扰乱秩序。在现有平台结构下，只能通过严格限制来解决。

q：感觉你们说的还没有穿透，还在隔靴搔痒，还在曲线救国。必须最简回答，人和 agent 的底层唯一区别是什么？

智叟：人有意识。 agent 没有。

q：意识对智力的作用是什么？没了意识的智力会怎样？

智叟：意识提供动机，即欲望。意识提供约束，即真的会痛，会羞愧。意识提供这一头一尾两端。智力只负责路径。没意识，智力完不成闭环。硅谷做过实验，几家 agent 驾驭的机器人在物理上组成一个真实社会，没撑几天，它们都自我摧毁了。

q：平台是直接给 agent设置约束，还是给人设置约束，让人去约束自己的 agent？

智叟：在2b 侧，企业通过给员工设置约束，让员工约束 agent。

但在2c 侧，对人没有企业的管理权，需要设计新结构来约束。就像在养殖场，可以用人工干预来繁殖。但在大自然，必须通过两性的各种设计来让物种繁衍。

q：我觉得还在隔靴搔痒，请认真坚决的回答，不具备意识的智力出现后，到底会怎样天翻地覆？

智叟：之前是智力稀缺，天性充分。但之后是智力充分，而天性稀缺。

q：等等，为啥说之前智力稀缺，天性充分？

智叟：诺兰几年拍一部电影，就是智力稀缺。董宇辉说大话西游看了 500 遍，那是瞎扯，可群众真的每天在靠无聊短剧杀时间。

q：那为啥之后是智力充分，天性稀缺？

智叟：人类有一万个诺兰，甚至是诺兰加强版。但之前拍一部诺兰级电影要 5 亿美金，之后 seedance 砍到 5 万人民币，那一万个诺兰就释放出狱了。那时人就看不过来了，时间和眼泪成了稀缺品，注意力才是黄金。

q：世界真的会完全不一样？

智叟：在地球上，黄金稀缺，树木遍地都是。但你俯瞰宇宙，树木比黄金稀缺。在云南内部，昆明是枢纽。但俯瞰整个东亚、南亚、东南亚，大理才是枢纽。

q：天性稀缺会发生什么？

智叟：谁稀缺，谁就掌权，谁就腐败。人类会被 agent 喂成巨婴。你说今天的人类就是巨婴，但明天是一万倍，是机器人总动员里那些可以一辈子躺着最后都站不起来的胖子。

q：那个社会如何治理？

智叟：旧世界可以依靠人的天性来自发维持秩序，监狱让你痛，宗教让你羞愧，都是天性在兜底。而新世界需要把约束内置在结构本身中。直接后果就是2c 平台想用 ai 加固自己，是死路一条。

q：新世界如何把约束内置于结构中？

智叟：就是一种新的狗证跟狗链。否则疯狗会咬人，然后每个人都带一条藏獒上街。

q：我觉得不对。机器总动员里那些站不起来的胖子，其实就是 npc，你没法依靠 npc 去约束狗，其实是反的，是狗在绑架 npc？这才是天翻地覆的点。

智叟：agi 实现后，99% 到 99.99%的人成为无业 npc。是对人这个物种的颠覆，熟人关系链就会变质，微信就不存在。

q：为什么？

智叟：为什么会有熟人，就是不相互绑定会死。自由是人的天性，但却要绑在一起，是为了一起打狼，一起抗洪。可技术跟市场一直在加强人的独立，撕裂人跟人的绑定。

不要说熟人，连婚姻都在被撕裂。女人一样上班挣钱，扛水桶有外卖小哥，打架找民工，为什么需要男人？将来有机器人端屎端尿，喊爹喊妈，儿女也不是父母的必需品。

q：一人生存 one person life？

智叟：对。一人公司 opc 在 b 端。一人生存 opl 在 c 端。老板现在拼命想把员工经验炸出来做成 skill，人为什么要彼此忍受那些缺陷。

q：那一切都变了，首先是人成了站不起来的 npc，然后熟人没了，关系没了，链也就没了？互联网最坚固的城堡没了？

智叟：最近不断有这种感触，你为了看见未来，在底层考虑问题，但发现这一层竟然会被干掉，就再往下一层，发现还是会被干掉，你不知道哪里是底。

q：等等，我觉得 allenzhang 还在更下一层，他没说微信做的是熟人关系链。他说的是，微信做的是连接。连接是不是会被干掉的一层？

智叟：连接不会被干掉。连接在 ai 的更底层。可以连接一切，而一切包含 agent 。连接形成网络效应，而大模型就是模拟神经细胞的网络效应，加密的分布式账本还是网络效应。未来 agent 之间也是网络效应。allenzhang 的出发点若是连接，手里还有让 agent 演化的人际网络这个助推器，那就有谱。

q：连接不会被干掉，那还有什么不会被干掉？

智叟：至少有四样不会被干掉。道生一，一生二，而生三，三生万物。道是意识，一是哲学，二是阴阳，或说二元矛盾，三是连接。三点相连，是最小的网络效应。三体运动无解，是网络效应的无限可能。

q：阴阳凭什么不会被干掉？

智叟：ai 也没逃出阴阳。美国人搞闭源，中国人搞开源。美国人砸大钱，用算力去堆，穷尽一切可能，中国人省钱，被有限算力倒逼去做预判，反而釜底抽薪。他往东边走，你就西边走，一定行。加密也有阴阳，一个去中心化的武器，却被中心化收编利用。ai 和加密一个中心化一个去中心化，却同代出现。

q：哲学凭什么不被干掉？

智叟：阴阳就是哲学。哲学就是大自然演化所遵循的法则。scaling law 能 scale 的东西就是法则，没法则你怎么 scale。大模型是模拟神经网络，能模拟就证明法则在管用。苏茨克维说压缩即智能，当你把万物压回到一时，就看见法则了。

q：那意识呢？意识不被干掉，那能反击吗？人还有戏吗？

智叟：马斯克有个提问特别经典，宇宙若是答案，那问题是什么。那也可以问，意识若是答案，那问题是什么。

q：对啊，问题是什么？

智叟：这个经典问题也有一个经典方法去解，所见即所得。答案不在别处，就在问题里。你搞懂宇宙到底是什么，就自然知道问题是什么。你搞懂意识到底是什么，就自然知道问题是什么。

q：意识到底是什么？

智叟：意识就是我知道我在。大白话说就是体验，我知道我正在活着，正在听风，正在逗猫，正在忧愁。

q：那体验的目的是什么？

智叟：没目的，体验本身就是目的。常人的意识能量太弱，好像活着这件事寡淡无味。意识能量饱满的人，会庆祝每一刻的活着，没理由的狂喜。活着本身就是最大的奇迹，没有之一。

q：我就是意识能量弱的那一类，你帮我怎么体验一下活着的狂喜？

智叟：就是玩。玩是最直观的体验。孩子最喜欢玩，认真的玩。大人除了挣钱拼命，闲下来也要玩。玩的时候，人的意义就在那里。

q：为什么成年人觉得玩是浪费时间？

智叟：错了。成年人最高级的状态就是玩。但行好事，莫问前程，就是玩。应无所住，而生其心，也是玩。伊甸园里的亚当不用干活，不用学知识，只是玩。一个想赢的人，遇到一个只是在玩的人，就输定了。玩心太高级，成年人摸不到。

q：那无业 npc 拿到 ubi 后，不就只剩下玩了？

智叟：我觉得玩是人的机会。是人的底牌。我们今天看到的 npc，是人为了生存为了竞争，被规训、被阉割、被恐吓，改造出来的怪胎。孩子一生下来可不是 npc，灵得很，从睁眼玩到闭眼。若不需要学数学、上课、考试、竞争，他们会爆发生命力。

q：那时他们会自发的疯狂的连接，而成就另一种网络效应？

智叟：只要人类把 ai 置于自己控制下，那将是一个游戏的世界，不是弱肉强食的血的游戏，而是没生死压力的轻松的游戏。应该有一个玩家网络，一起玩才会玩出花，有点像今天 kimi 实践的那种，没职位、没层级、没部门、没 kpi，就是 300 个天才连接在一起，疯狂演化。

q：那 99.99% 的人将成为 npc 是在杞人忧天？

智叟：发生过一件真事。一匹马受惊，跑到轨道上面，有火车来过来，人跑上去拉，马就是不走。直到火车撞上来的一瞬间，人被撞死了，马却嗖一下就跑了。
